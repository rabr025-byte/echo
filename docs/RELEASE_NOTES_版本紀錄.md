# Echo — 版本發布紀錄(Release Notes)

> 建立日期:2026-08-03　最後更新:2026-08-03
> 版本規則:v0.x 為開發期,六階段完成後上線改 v1.0。

---

## v1.0.1 — 2026-08-03
**公開前版權處理**
- 預設題庫由 IPAS 真實考題,替換為全原創範例題庫(16 選擇 + 3 申論,主題為科技常識與邏輯思考)。
- 移除舊 IPAS 題庫檔,全專案清除相關殘留。
- 資料結構不變,App 邏輯未動。

## v1.0 — 開發期最終功能批
**題庫持久化 + 統計**
- 上傳題庫存入 localStorage,重開仍在,可切換多題庫。
- 題庫刪除功能(二次確認防誤觸,連帶清除進度)。
- 記住上次使用題庫,啟動自動載入,顯示儲存空間用量。
- 圖鑑矩陣:每題掌握度視覺化(全對/對多於錯/常錯/未作答)。
- 歷史紀錄排行:依得分排序歷次成績。

## v0.9.2
**題庫製作指南**
- 設定內建「自己做題庫」:提供考試導向、生活導向兩種可複製 AI 指令,附格式參考與分批生成提示。

## v0.9.1
**iOS 安全區修復**
- 改用容器層 safe-area padding,修正設定按鈕與狀態列重疊問題。

## v0.9
**安全區 + 圖示升級**
- 加入 viewport-fit 與安全區處理。
- 全面以 lucide 線性圖示取代 emoji,提升質感。

## v0.8
**導覽 + 申論 + 紙感優化**
- 互動式新手導覽(聚光燈高亮真實元素)。
- 申論題型:AI 依評分要點給分,60 分通過制,接回連擊與計分。
- 紙感主題 Kinfolk 化(溫潤米色、陶土色、無光暈)。

## v0.7
**留存系統第二批**
- 幽靈對手:與過往最佳紀錄賽跑,破紀錄給徽章。
- 每日任務:每日三目標,全完成慶祝。

## v0.6
**留存系統第一批**
- 連續登入系統 + 月曆熱力圖。
- 賭注模式:分數加倍、答錯扣雙倍生命。
- 設定頁修復(取消/儲存並排,儲存後自動關閉)。

## v0.5.x
**UI / 多巴胺**
- 選單改版(主次焦點、卡片入場、標題光暈)。
- 答題爽感:綠光脈衝、連擊大字、里程碑閃光粒子、分級慶祝。
- 生命值改為愛心(碎裂動畫)、combo 打擊感強化、測試模式。

## v0.1 – v0.4
**基礎建置**
- v0.1 Vite + React + TS 骨架,動態標題。
- 題庫模組化:格式定義、驗證器、多題庫進度隔離、上傳。
- 遊戲邏輯:四模式、連擊、生命、錯題本。
- v0.4 AI 功能:設定頁、AI 解讀、AI 幻影、AI 生成題庫、三主題切換。
