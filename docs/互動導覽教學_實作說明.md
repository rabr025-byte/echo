# 互動導覽教學 — 實作說明(可直接參考套用)

> 這份文件說明一個「首次開啟的互動式新手導覽」怎麼做:全螢幕遮罩在真實 UI 元素上「挖洞」高亮,搭配提示卡逐步introduce。附完整程式碼,可直接改用。

---

## 一、核心原理

用一個全螢幕遮罩層,在要介紹的**真實 UI 元素**位置挖一個洞把它高亮,其餘變暗,搭配一張提示卡逐步推進。不是另外畫假畫面,而是高亮畫面上真實存在的元素。

## 二、三個關鍵技術點

**1. 用 `data-tour` 標記目標**
在要高亮的真實元素加屬性,例如 `<button data-tour="start">`。導覽元件靠 `document.querySelector('[data-tour="start"]')` 找到它。

**2. 挖洞高亮用超大 box-shadow(整個效果的核心技巧)**
不用真的裁切遮罩。做法:一個透明方塊對齊目標元素位置,給它範圍極大的陰影:
```
box-shadow: 0 0 0 9999px rgba(0,0,0,0.78);
```
這個 9999px 陰影往外鋪滿整個畫面變暗,而方塊本身透明,形成「中間亮、周圍暗」的聚光燈效果。再加邊框凸顯。

**3. 用 `getBoundingClientRect()` 定位**
拿到目標元素的實際座標與大小,遮罩洞和提示卡依此動態擺放。視窗 resize 要重新測量。提示卡位置邏輯:目標在畫面上半就把卡片放下面,反之放上面,避免擋住高亮元素。

## 三、觸發時機的坑(最重要)

一定要等被介紹的畫面**真的渲染出來**再啟動導覽,否則 `querySelector` 找不到元素。做法:等資料載入完成、主畫面已顯示,才觸發導覽。程式碼有防呆,找不到元素會退化成置中卡片、不會崩,但就沒有高亮效果。

## 四、耦合度低

被介紹的元件只需要加 `data-tour` 屬性,不需要知道導覽邏輯。之後改導覽步驟或文案,只動 `Tutorial.tsx` 一個檔案。

## 五、完整程式碼

### Tutorial.tsx

```tsx
// Tutorial.tsx
// 互動式導覽:全螢幕遮罩挖洞高亮真實 UI 元素,逐步推進
import { useState, useEffect, useCallback } from 'react';

interface Step {
  target: string;   // 對應畫面元素的 data-tour 值;空字串 = 置中卡片(不高亮)
  title: string;
  text: string;
}

// 導覽步驟:target 要跟畫面上的 data-tour 屬性對應
const STEPS: Step[] = [
  { target: '', title: '歡迎', text: '開場白,置中顯示。' },
  { target: 'start', title: '主按鈕', text: '高亮 data-tour="start" 的元素。' },
  { target: 'menu', title: '選單', text: '高亮 data-tour="menu" 的元素。' },
  { target: '', title: '結束', text: '結尾,置中顯示。' },
];

const KEY = 'app:tutorial_done';
export const isTutorialDone = () => !!localStorage.getItem(KEY);

interface Props { onDone: () => void; }

export const Tutorial = ({ onDone }: Props) => {
  const [idx, setIdx] = useState(0);
  const [rect, setRect] = useState<DOMRect | null>(null);
  const step = STEPS[idx];

  // 找目標元素,取得它的座標與大小
  const measure = useCallback(() => {
    if (!step.target) { setRect(null); return; }
    const el = document.querySelector(`[data-tour="${step.target}"]`);
    if (el) {
      el.scrollIntoView({ block: 'center', behavior: 'instant' as ScrollBehavior });
      setRect(el.getBoundingClientRect());
    } else {
      setRect(null); // 找不到就當置中卡片,不會崩
    }
  }, [step.target]);

  // 每步變化 + 視窗 resize 都重新測量
  useEffect(() => {
    measure();
    window.addEventListener('resize', measure);
    return () => window.removeEventListener('resize', measure);
  }, [measure]);

  const finish = () => { localStorage.setItem(KEY, '1'); onDone(); };
  const next = () => { idx < STEPS.length - 1 ? setIdx(idx + 1) : finish(); };

  const pad = 8; // 高亮框比元素大一圈
  // 目標在畫面上半 → 提示卡放下方;下半 → 放上方(避免卡片擋住高亮)
  const cardBelow = !rect || rect.top < window.innerHeight / 2;

  return (
    <div className="fixed inset-0 z-[100]">
      {/* 遮罩:有目標就挖洞,沒有就整片變暗 */}
      {rect ? (
        <div
          className="absolute rounded-2xl transition-all duration-300 pointer-events-none"
          style={{
            left: rect.left - pad,
            top: rect.top - pad,
            width: rect.width + pad * 2,
            height: rect.height + pad * 2,
            // 關鍵技巧:超大陰影往外鋪滿整個畫面變暗,方塊本身透明 = 聚光燈效果
            boxShadow: '0 0 0 9999px rgba(0,0,0,0.78)',
            border: '2px solid #d4af37', // 高亮框顏色,自行替換
          }}
        />
      ) : (
        <div className="absolute inset-0 bg-black/[0.78]" />
      )}

      {/* 提示卡:依目標位置動態擺上方或下方 */}
      <div
        className="absolute left-1/2 -translate-x-1/2 w-[85%] max-w-sm transition-all duration-300"
        style={
          rect
            ? cardBelow
              ? { top: rect.bottom + pad + 16 }
              : { bottom: window.innerHeight - rect.top + pad + 16 }
            : { top: '50%', transform: 'translate(-50%, -50%)' }
        }
      >
        <div className="bg-white border rounded-2xl p-5 shadow-2xl">
          <div className="text-xs opacity-50 mb-1">{idx + 1} / {STEPS.length}</div>
          <div className="text-lg font-black mb-1">{step.title}</div>
          <p className="text-sm opacity-80 leading-relaxed mb-4">{step.text}</p>
          <div className="flex justify-between items-center">
            <button onClick={finish} className="text-xs opacity-50">跳過</button>
            <button onClick={next} className="px-6 py-2.5 rounded-xl bg-black text-white text-sm font-bold">
              {idx < STEPS.length - 1 ? '下一步' : '開始!'}
            </button>
          </div>
        </div>
      </div>
    </div>
  );
};
```

### 在被介紹的畫面元素上標記目標

```tsx
<button data-tour="start">開始</button>
<div data-tour="menu">...</div>
```

### 在 App 掛載(關鍵:等畫面渲染好才啟動)

```tsx
const [showTutorial, setShowTutorial] = useState(false);

useEffect(() => {
  // 等資料載入完、主畫面已顯示,再啟動導覽,否則 querySelector 找不到元素
  if (dataReady && view === 'menu' && !isTutorialDone()) {
    setShowTutorial(true);
  }
}, [dataReady, view]);

// render:
{showTutorial && <Tutorial onDone={() => setShowTutorial(false)} />}
```

## 六、套用檢查清單

1. `box-shadow: 0 0 0 9999px` 是整個效果的核心——一個透明方塊配超大陰影就做出聚光燈,不用裁切遮罩。
2. 一定要等目標元素渲染完才啟動,不然 `querySelector` 回傳 null(有防呆,退化成置中卡片,不會崩)。
3. 顏色、圓角、字體換成該專案的設計 token,範例裡是寫死的金色/黑白。
4. 被介紹的元件只加 `data-tour` 屬性,不需要知道導覽存在,耦合度低。
5. 測試方式:清掉 localStorage 的 `app:tutorial_done`,或用無痕視窗看首次體驗。
