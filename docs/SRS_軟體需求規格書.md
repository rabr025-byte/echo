## 1. 文件目的與範圍

本文件定義 Echo 的功能性與非功能性需求。Echo 是一個純前端的通用刷題遊戲引擎:遊戲外殼固定,題庫為可替換資料。使用者可用預設題庫、上傳自製 JSON、或以 AI 生成題庫。本規格適用於 v1.0.1 版本。

不在範圍內:後端服務、帳號系統、跨裝置同步、金流。

---

## 2. 名詞定義

| 名詞 | 定義 |
|---|---|
| 題庫(Bank) | 一組題目的集合,含唯一 bankId、顯示名稱與題目陣列 |
| 題目(Question) | 選擇題或申論題,含題幹、選項/評分要點、正解 |
| combo | 連續答對數,影響得分與視覺回饋 |
| 幽靈(Ghost) | 使用者上一次最佳紀錄,作為對戰進度參考 |
| 掌握度 | 依作答對錯次數判定的單題熟練程度 |

## 3. 功能性需求(FR)

### FR-1 題庫管理
- FR-1.1 系統應於啟動時載入內建預設題庫。
- FR-1.2 使用者應能上傳自製 JSON 題庫。
- FR-1.3 系統應於上傳時驗證題庫格式,並以自然語言回報錯誤(哪一題、什麼問題)。
- FR-1.4 上傳的題庫應持久化保存(localStorage),重新開啟後仍存在。
- FR-1.5 使用者應能在多個已存題庫間切換。
- FR-1.6 使用者應能刪除自製題庫,刪除需二次確認,並連帶清除該題庫的進度資料。
- FR-1.7 預設題庫不可刪除。
- FR-1.8 系統應記住上次使用的題庫,下次啟動自動載入。

### FR-2 答題與計分
- FR-2.1 系統應提供多種模式:標準(10題)、進階(50題)、限時、極限(答錯即止)、錯題本、AI 幻影、申論。
- FR-2.2 答對得分為 100 + min(combo×10, 500)。
- FR-2.3 連續答對時 combo 累加,答錯歸零。
- FR-2.4 生命值上限 100,答錯扣 20(以 5 顆愛心呈現),歸零則結束。
- FR-2.5 賭注模式:單題得分加倍,答錯扣雙倍生命。
- FR-2.6 答錯題目自動收入錯題本,可單獨練習。

### FR-3 視覺回饋
- FR-3.1 答對應呈現即時正向回饋(分數浮動、綠光脈衝)。
- FR-3.2 每 5 連擊應觸發里程碑特效(閃光、粒子、光環)。
- FR-3.3 答錯應呈現震動與生命扣減回饋。
- FR-3.4 結算畫面應依成績分級呈現不同慶祝程度。

### FR-4 AI 功能(需使用者提供 API Key)
- FR-4.1 AI 解讀:針對單題提供 AI 解釋。
- FR-4.2 AI 幻影:即時生成一題新題目。
- FR-4.3 AI 生成題庫:依使用者提供的文字生成完整題庫。
- FR-4.4 申論評分:依評分要點給 0–100 分與短評,60 分以上視為通過。
- FR-4.5 AI 供應商架構應可擴充(預設 Gemini)。

### FR-5 留存系統
- FR-5.1 連續登入:每日首次開啟記錄,提供月曆熱力圖檢視。
- FR-5.2 每日任務:每日三項目標,完成給予回饋。
- FR-5.3 幽靈對手:與使用者過往最佳紀錄比較進度,破紀錄給予徽章。

### FR-6 統計與紀錄
- FR-6.1 圖鑑:以矩陣呈現每題掌握度(全對/對多於錯/常錯/未作答)。
- FR-6.2 歷史紀錄:依得分排序呈現歷次成績。

### FR-7 新手導覽
- FR-7.1 首次開啟應提供互動式導覽,高亮實際介面元素逐步說明。
- FR-7.2 導覽應可跳過,完成後不再自動出現。

### FR-8 主題
- FR-8.1 應提供至少三種可切換主題(暗夜、紙感、霓虹)。
- FR-8.2 主題切換應即時預覽。

## 4. 非功能性需求(NFR)

| 編號 | 類別 | 需求 |
|---|---|---|
| NFR-1 | 平台 | 以行動裝置(iOS Safari)為主要使用場景,需適配安全區 |
| NFR-2 | 效能 | 首次載入 JS 壓縮後應在合理範圍(目前約 66KB gzip) |
| NFR-3 | 隱私 | 所有使用者資料僅存於本機,不上傳伺服器 |
| NFR-4 | 安全 | 不內建任何 API Key;使用者金鑰僅存於其本機 |
| NFR-5 | 可維護 | 顏色以 CSS 變數管理,題庫與遊戲邏輯分離 |
| NFR-6 | 相容 | 題庫格式向後相容,新增欄位不破壞舊題庫 |

## 5. 資料需求

### 題庫 JSON 結構
```
QuestionBank {
  bankId: string        // 唯一識別碼(進度隔離用)
  displayName: string   // 顯示名稱
  name: string
  author?: string
  description?: string
  questions: Question[]
}
Question {
  id: string
  type?: 'choice' | 'essay'
  question: string
  options: string[]     // 選擇題≥2;申論題為 []
  answer: number        // 選擇題正解索引(0起)
  rubric?: string       // 申論題評分要點
  explanation?: string
  source?: string
  subject?: number
  category?: number
}
```

### localStorage 鍵值
| 鍵 | 用途 |
|---|---|
| echo:banks | 已存題庫清單 |
| echo:activeBank | 目前使用題庫 |
| echo:{bankId}:stats | 各題對錯次數 |
| echo:{bankId}:mistakes | 錯題本 |
| echo:{bankId}:records | 歷史紀錄 |
| echo:{bankId}:ghost:{mode} | 幽靈最佳紀錄 |
| echo:settings | 主題/AI/開關設定 |
| echo:streak | 連續登入 |
| echo:daily | 每日任務 |
| echo:tutorial_done | 導覽完成旗標 |

## 6. 限制與假設

- 純前端架構,無後端;所有運算在瀏覽器完成。
- AI 功能依賴使用者自備的 API Key 與網路連線。
- localStorage 容量上限約 5MB,大量題庫需自行管理。
- 申論評分由 AI 判定,結果僅供參考,非權威評分。
