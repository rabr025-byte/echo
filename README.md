# Echo

> 通用刷題遊戲引擎 — 把刷題變成有回饋感的遊戲,題庫可自由替換。

最後更新:2026-08-03　·　版本:v1.0.1

---

## 這是什麼

Echo 是一個純前端的刷題遊戲。核心是遊戲外殼(連擊、生命值、特效、留存系統),題庫是可替換的資料。你可以用預設題庫、上傳自己的 JSON、或用 AI 把筆記生成題庫。沒有後端、不需註冊、資料全存在你自己的裝置。

打開時顯示 `Echo`,載入題庫後標題變成 `Echo · {題庫名}`。

---

## 主要功能

- **七種模式**:標準、進階、限時、極限、錯題本、AI 幻影、申論挑戰
- **遊戲化**:連擊加分、愛心生命值、賭注模式、打擊感特效、分級慶祝
- **留存系統**:連續登入月曆、每日任務、幽靈對手(跟過去的自己賽跑)
- **統計**:圖鑑矩陣(每題掌握度)、歷史紀錄排行
- **AI 功能**(需自備 API Key):解讀題目、即時生題、生成題庫、申論評分
- **題庫管理**:上傳、格式驗證、持久化、多題庫切換、刪除
- **三主題**:暗夜、紙感、霓虹,可即時切換
- **新手導覽**:首次開啟互動教學

## 技術棧

React 18 + TypeScript + Vite + Tailwind CSS + lucide-react。AI 使用 Gemini(可擴充其他供應商)。純前端,無後端。

---

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 建置(tsc + vite)
```

建置前請確保 `npx tsc -b && vite build` 通過。

---

## 題庫格式

```json
{
  "bankId": "唯一識別碼",
  "displayName": "顯示名稱",
  "name": "完整名稱",
  "questions": [
    { "id": "q1", "question": "題目", "options": ["A","B","C","D"], "answer": 0, "explanation": "說明" },
    { "id": "e1", "type": "essay", "question": "申論題", "options": [], "answer": 0, "rubric": "評分要點" }
  ]
}
```

App 內設定頁有「自己做題庫」,提供可複製的 AI 指令,貼上教材即可生成。

---

## 隱私

所有資料(進度、錯題、紀錄、設定、API Key)僅儲存在使用者本機的 localStorage,不上傳任何伺服器。AI 功能由使用者瀏覽器直接呼叫,金鑰不經過第三方。
